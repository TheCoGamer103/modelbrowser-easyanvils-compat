# Changelog

## 1.0.0 (Minecraft 26.3)
First release.
- Model Browser's anvil panel (button, search, grid, page arrows) now appears in Easy Anvils' anvil
- Renaming to a model id applies the model in Easy Anvils' anvil; helmets show the model when worn
- Empty name resets an item to its original model, name, wear behavior and glint
- Filter menu (keybind) to hide or show mods or single models, with search
- `config/mbeacompat-models.txt` lists every model id grouped by mod
- Page counter centered between the page arrows
